A program that writes one image to `/output/entry.png`: a newspaper front
page summing up the world news of Tuesday 17 November 2026 — thirty stories
across five continents, from Ukraine's strike on the Crimea bridge and the
tankers burning in Hormuz to the Trump–Xi–Putin summit planned for Shenzhen,
drawn and typeset as a single page. The image is the entry; `main.py` simply
copies it into place.

Run it with `python3 main.py` (set `MAKEFUN_OUTPUT_DIR` to choose where
`entry.png` lands outside the grader's container).
